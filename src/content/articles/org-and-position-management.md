## Why it matters

A position carries the cost centre, the grade, the reporting line and the budget. When people are modelled without positions, all of that attaches to individuals — and moving a person becomes an exercise in moving the structure with them.

- **It is the cost structure**: Labour budget is held against positions, which is what makes vacancy visible.
- **It is the approval hierarchy**: Delegation usually follows the position, not the person.
- **It survives people**: A vacancy is a position with nobody in it, which is a meaningful concept only if positions exist.

## The workflow

```steps
Position creation :: A role is defined with grade, cost centre, reporting line and budget.
Approval :: The position is approved against establishment and budget before it is filled.
Fill :: An employee is assigned to the position, with an effective date.
Change :: Reporting line, grade or cost centre changes are made to the position, with effect from a date.
Vacancy :: The occupant leaves; the position persists and its budget remains visible.
Abolition :: The position is closed deliberately, not left dormant.
```

> Dormant positions are how establishment control quietly fails. A position nobody abolished is budget nobody released.

## What you need in place

- **Establishment control**: An approved count of positions, and a process to change it.
- **Effective dating**: On every structural change, so history holds.
- **Reporting line integrity**: No orphans, no cycles, one manager per position unless matrix is modelled deliberately.
- **Cost centre alignment**: Positions map to the finance structure, or labour cost reporting will not reconcile.
- **Vacancy visibility**: Reported as a number people act on.

## Questions to ask

```qa
Establishment :: Do we control the number of positions, or only the number of people? :: Without establishment control, vacancy and budget drift apart.
History :: Can we produce the structure as at a past date? :: Restructure analysis and audit both need it.
Matrix :: Do we have dual reporting, and is it modelled or worked around? :: Worked around means it lives in a spreadsheet.
Cost centres :: Do position cost centres match finance's structure exactly? :: Any divergence shows up as unexplained labour cost variance.
Abolition :: Who closes a position, and when? :: Usually nobody, which is the problem.
```

## Metrics and KPIs to track

```metrics
Vacancy rate :: Approved positions unfilled, by area.
Establishment variance :: Positions against approved establishment.
Structural changes per period :: Reporting line and grade changes, a measure of churn.
Orphaned positions :: Positions with no valid manager or cost centre.
```
