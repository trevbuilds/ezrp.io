## Why it matters

Mandatory training is a compliance record with legal weight. Development is an investment with a return that is harder to measure. Running both as "courses assigned and completed" flatters the first and starves the second.

- **Mandatory training is evidence**: Completion has to be provable, with dates.
- **Development is capability**: Measured by what people can do afterwards, not by attendance.
- **Both feed rostering**: A qualification gained should unlock an assignment; one expired should block it.

## The workflow

```steps
Needs identification :: Requirements derived from role, regulation and capability gaps.
Assignment :: Training assigned with a due date, automatically where it is role-driven.
Delivery :: Completed online, in person or on the job.
Assessment :: Competence confirmed where the obligation requires it, not just attendance.
Record :: Completion and expiry recorded against the person.
Effectiveness :: Whether capability actually changed.
```

> Completion is not competence. For anything safety-critical the record should be of assessed competence with an assessor, because that is what an investigator will ask for.

## What you need in place

- **Role-driven assignment**: Requirements follow the position, so a role change re-assigns automatically.
- **Expiry and refresher tracking**: Feeding the compliance register.
- **Competence against completion**: Distinguished in the data.
- **Integration with rostering**: Qualifications gate assignment.
- **Cost tracking**: Development spend visible by area.

## Questions to ask

```qa
Assignment :: Does a role change automatically re-assign required training? :: If manual, it will be missed.
Competence :: Do we record assessed competence or just completion? :: For safety-critical work these are not the same.
Expiry :: Which qualifications expire, and what happens as they approach? :: Should flow into compliance and rostering.
Effectiveness :: How do we know training changed anything? :: Attendance is not an outcome measure.
Spend :: Where is development investment going, by area? :: Usually unevenly, and usually unexamined.
```

## Metrics and KPIs to track

```metrics
Mandatory completion :: Within the required window, by area.
Competence currency :: Assessed competencies current against requirement.
Capability coverage :: Critical skills with sufficient qualified people.
Development spend :: Investment per employee, by area.
```
